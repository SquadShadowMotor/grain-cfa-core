# Зерно.ЦФА — основной функционал

Сокращённая конкурсная версия прототипа платформы цифровых финансовых активов с зерновым обеспечением.

Оригинальный интерактивный прототип: https://grain-trust-link.base44.app

## Что включено

- Маркетплейс восьми демонстрационных выпусков, поиск и фильтрация по культуре.
- Карточка выпуска: параметры, физическое обеспечение, статусы оракула и риски.
- Учебная покупка: проверка суммы, расчёт количества токенов и добавление в портфель.
- Портфель с сохранением между перезагрузками страницы.
- Четырёхшаговый мастер заявки на выпуск: партия, проверка готовности, параметры, предпросмотр.
- Сохранение черновика и отправленной демо-заявки в браузере.

Это ограниченная версия. GrainX DEX, вторичный рынок, карта, страховые операции, авторизация, реальные расчёты и интеграции с ФГИС/оператором ЦФА в неё не входят.

## Происхождение кода

Отобранные исходники доступны в редакторе принадлежащего автору приложения Base44 и перенесены через просмотр кода. Структура маркетплейса, демонстрационные данные, компонент статусов и цветовая схема сохранены. Навигация сокращена; покупка, портфель и заявки адаптированы для самостоятельной работы без Base44 SDK и серверов Base44. Это адаптация части исходников, а не полный экспорт приложения. Файлы с ключами, данными пользователей и служебными настройками Base44 не включены.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm ci
npm run dev
```

Адрес будет напечатан в терминале. Для проверки и сборки:

```sh
npm test
npm run build
npm run preview
```

`dist/` содержит готовую статическую сборку. Hash-навигация позволяет размещать её на статическом хостинге без настройки перенаправлений. Сборка не содержит внешних шрифтов и карт.

## Сценарий для жюри

1. Найдите пшеницу в маркетплейсе, откройте карточку и вкладку обеспечения.
2. Купите 100 000 ₽ в демо-режиме; это 100 токенов с условным номиналом 1 000 ₽.
3. Откройте «Мои активы», затем обновите страницу: позиция сохранится.
4. В «Выпустить ЦФА» пройдите четыре шага, измените параметры, сохраните черновик или отправьте демо-заявку.
5. Проверьте заявку в «Моих активах».

Все данные — демонстрационные. Нет реальных платежей, выпуска финансовых инструментов или проверки обеспечения. Данные хранятся только в localStorage текущего браузера и не синхронизируются между пользователями. Статусы оракулов — статичный демонстрационный снимок исходного прототипа. Очистка данных сайта удаляет портфель и заявки.
